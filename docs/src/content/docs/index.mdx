## Quick start

```sh
composer require solvebeam/twinfield
```

```php
use SolveBeam\Twinfield\Finder\FinderType;
use SolveBeam\Twinfield\Twinfield;

$twinfield = Twinfield::create($accessTokenProvider)->company('1000');

foreach ($twinfield->offices()->list() as $office) {
    echo $office->code, ' ', $office->name, PHP_EOL;
}

$debtors = $twinfield->finder(FinderType::Dimensions)
    ->option('dimtype', 'DEB')
    ->limit(10)
    ->get();
```

## Why this SDK

<CardGrid>
	<Card title="OAuth2 built in" icon="padlock">
		Log in once, store the refresh token, and access tokens are refreshed and cached for you. The cluster URL of
		the organisation is found automatically.
	</Card>
	<Card title="Fluent Finder" icon="magnifier">
		Search dimensions, countries and more with options, limits and lazy pagination: `all()` fetches the next page
		only when your loop needs it.
	</Card>
	<Card title="PSR all the way" icon="puzzle">
		Bring your own PSR-18 HTTP client, PSR-17 factories, PSR-6 cache and PSR-3 logger. Nothing is hard-wired.
	</Card>
	<Card title="Strict models" icon="approve-check">
		Read models are typed and validated. Unexpected responses throw instead of quietly turning into empty
		values.
	</Card>
</CardGrid>
