The repository has old manuals of the Twinfield web services in [`manuals/`](https://github.com/solvebeam/twinfield-php/tree/main/manuals), kept for reference. They describe the XML web services ([ProcessXml](/guides/process-xml/)) and some classic SOAP services, often with more detail than the current documentation.

They can be outdated. The [Twinfield API documentation](https://developers.twinfield.com/documentation/api/) is leading, and where live responses differ from the documentation the SDK follows the live responses: see [Differences with the documentation](/guides/documentation-differences/). For the current service definitions, see the WSDL files in [`wsdl/`](https://github.com/solvebeam/twinfield-php/tree/main/wsdl).
