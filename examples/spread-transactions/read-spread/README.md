# Read spread

Reads the spread of a sales or purchase transaction: the intermediate account, the periods and the spread transactions Twinfield made for it.

<!-- twinfield-documentation:start -->
Twinfield documentation: [Spread transactions](https://developers.twinfield.com/documentation/api/transaction-data/spread-transactions/).
<!-- twinfield-documentation:end -->

A spread divides the costs or revenue of one invoice over a number of periods, e.g. a yearly subscription over twelve months (kosten- of opbrengstenverdeling).

`get($dayBook, $number)` returns a `Spread`:

- `$spread->original`: the transaction you asked for (company, day book and number).
- `$spread->settings`: the spread settings, or `null` when the transaction is not spread. `intermediateAccount` is the balance sheet account the amounts are spread from. The periods are either the same for the whole transaction (`startPeriod` and `endPeriod`) or set per detail line (`lines`, when `isByLines()` is true).
- `$spread->spreadTransactions`: the transactions Twinfield made, each a `TransactionReference`. One moves the amounts of the detail lines to the intermediate account in the period of the original transaction; the others spread them from there over the periods. Read them with `journalTransactions()->get()`.

Only sales and purchase transactions can be spread. Twinfield refusals are thrown as `ProcessXmlException`.

## Code

```php
$twinfield = Example::twinfield();

// E.g. `INK 202600021`: day book and number of a sales or purchase transaction.
[, $dayBook, $number] = array_pad($argv ?? [], 3, null);

if ($dayBook === null || $number === null) {
    echo 'Usage: php example.php <day book> <transaction number>', PHP_EOL;

    exit(0);
}

try {
    $spread = $twinfield->spreadTransactions()->get($dayBook, (int) $number);
} catch (ProcessXmlException $exception) {
    echo 'Refused: ', $exception->getMessage(), PHP_EOL;

    exit(1);
}

echo 'Original: ', $spread->original->dayBook, ' ', $spread->original->number, PHP_EOL;

if ($spread->settings === null) {
    echo 'Not spread.', PHP_EOL;

    exit(0);
}

echo 'Intermediate account: ', $spread->settings->intermediateAccount, PHP_EOL;

if ($spread->settings->isByLines()) {
    foreach ($spread->settings->lines as $line) {
        echo 'Line ', $line->lineId, ': ', $line->startPeriod, ' to ', $line->endPeriod, PHP_EOL;
    }
} else {
    echo 'Periods: ', $spread->settings->startPeriod, ' to ', $spread->settings->endPeriod, PHP_EOL;
}

foreach ($spread->spreadTransactions as $transaction) {
    echo 'Spread transaction: ', $transaction->dayBook, ' ', $transaction->number, PHP_EOL;
}
```

## Run

```sh
php examples/spread-transactions/read-spread/example.php INK 202600021
```
