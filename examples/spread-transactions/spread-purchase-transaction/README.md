# Spread purchase transaction

Spreads the costs of a purchase transaction over a number of periods, e.g. a yearly subscription over twelve months.

<!-- twinfield-documentation:start -->
Twinfield documentation: [Spread transactions](https://developers.twinfield.com/documentation/api/transaction-data/spread-transactions/).
<!-- twinfield-documentation:end -->

> **This example changes data in Twinfield.** Only run it on a test administration. The spread transactions of a final transaction are final too: they cannot be changed or deleted.

Twinfield makes the spread transactions itself. You give the intermediate account (a balance sheet account, e.g. prepaid expenses) and the first and last period:

- `postFinal()` spreads a **final** transaction, `postProvisional()` a **provisional** one. The example reads the transaction first and picks the right one.
- `postFinalByLines()` and `postProvisionalByLines()` take the periods per detail line, as `SpreadLine` objects with `DetailLine::$id` of the transaction: `new SpreadLine($transaction->details[0]->id, Period::of(2026, 1), Period::of(2026, 12))`. Lines you leave out are not spread.
- `undo()` removes the spread of a provisional transaction again.

All of them return a `Spread`, with the settings and the spread transactions; see [Read spread](../read-spread/).

## Code

```php
$twinfield = Example::twinfield();

// E.g. `INK 202600021 2500 2026/01 2026/12`: a purchase transaction, the intermediate account
// and the first and last period of the spread.
[, $dayBook, $number, $intermediateAccount, $start, $end] = array_pad($argv ?? [], 6, null);

if ($dayBook === null || $number === null || $intermediateAccount === null || $start === null || $end === null) {
    echo 'Usage: php example.php <day book> <transaction number> <intermediate account> ',
        '<start period> <end period>', PHP_EOL;

    exit(0);
}

$spreads = $twinfield->spreadTransactions();

try {
    $transaction = $twinfield->purchaseTransactions()->get($dayBook, (int) $number);
    $existing = $spreads->get($dayBook, (int) $number);

    if ($existing->isSpread()) {
        echo 'Already spread in ', count($existing->spreadTransactions), ' transactions.', PHP_EOL;

        exit(0);
    }

    $from = Period::fromString($start);
    $to = Period::fromString($end);

    // A final transaction is spread with postFinal(), a provisional one with postProvisional().
    $spread = $transaction->header->status === TransactionStatus::Final
        ? $spreads->postFinal($dayBook, (int) $number, $intermediateAccount, $from, $to)
        : $spreads->postProvisional($dayBook, (int) $number, $intermediateAccount, $from, $to);
} catch (TransactionNotFoundException $exception) {
    echo 'Not found: ', $exception->reason, PHP_EOL;

    exit(1);
} catch (ProcessXmlException $exception) {
    echo 'Refused: ', $exception->getMessage(), PHP_EOL;

    exit(1);
}

echo 'Spread ', $dayBook, ' ', $number, ' (', $transaction->value(), ' ', $transaction->header->currency, ') over ',
    $start, ' to ', $end, ' through ', $intermediateAccount, PHP_EOL;

foreach ($spread->spreadTransactions as $spreadTransaction) {
    echo 'Spread transaction: ', $spreadTransaction->dayBook, ' ', $spreadTransaction->number, PHP_EOL;
}
```

## Run

The write guard of the examples blocks changes unless you allow them for a company in `TWINFIELD_WRITE_COMPANIES`:

```sh
TWINFIELD_COMPANY=1002_3 TWINFIELD_ALLOW_WRITES=1002_3 php examples/spread-transactions/spread-purchase-transaction/example.php INK 202600021 2500 2026/01 2026/02
```
