# Create time entry

Saves the time and kilometres a user wrote on a project and an activity on one day.

<!-- twinfield-documentation:start -->
Twinfield documentation: [Time entry](https://developers.twinfield.com/documentation/api/transaction-data/time/).
<!-- twinfield-documentation:end -->

> **This example changes data in Twinfield with `--save`.** Only run it on a test administration: the Twinfield documentation has no way to delete a time entry through the API.

A time entry has a header (the kind of entry, the user, the date, the project and the activity) and lines:

- `time($duration, …)` adds a time line, with an optional `description`, `billable` and `rate`.
- `quantity($quantity, …)` adds a quantity line, e.g. kilometres, with an optional `rate` and `billable`. The quantity is a numeric string (`'12.5'`), never a float.

`TimeEntryInput::direct()` is time on a project; `indirect()` and `personal()` are for time that is not for a customer, such as a meeting or leave.

Twinfield creates the entry when it does not exist yet and updates it otherwise. `save()` returns a `TimeEntry` with what Twinfield added: the names, the rate of each line and its internal and external value. To save several entries in one request, e.g. a whole week, use `saveMany()`: it returns a result per entry and does not throw when some are refused.

Without `--save` the example only shows the XML it would send.

## Code

```php
$twinfield = Example::twinfield();

// E.g. `JDOE P0099 A010`: the user the time is for, a project and an activity of the company.
$arguments = array_values(array_filter(
    array_slice($argv ?? [], 1),
    static fn (string $argument): bool => $argument !== '--save',
));
[$user, $project, $activity] = array_pad($arguments, 3, null);

if ($user === null || $project === null || $activity === null) {
    echo 'Usage: php example.php <user> <project> <activity> [--save]', PHP_EOL;

    exit(0);
}

// Four units of time and 12.5 kilometres on one day. Twinfield takes the rates and whether the
// lines are billable from the project and the activity, unless you pass them.
$input = TimeEntryInput::direct($user, new DateTimeImmutable('today'), $project, $activity)
    ->time(240, description: 'Implementation')
    ->quantity('12.5');

if (!in_array('--save', $argv ?? [], true)) {
    echo 'Dry run; add --save to save the time entry (it can\'t be deleted through the API):', PHP_EOL, PHP_EOL;
    echo Example::xml(TimeEntryXmlWriter::request((string) $twinfield->companyCode(), $input)), PHP_EOL;

    exit(0);
}

try {
    $entry = $twinfield->timeEntries()->save($input);
} catch (ProcessXmlException $exception) {
    foreach ($exception->result->messages() as $message) {
        echo $message->type->value, ' at ', $message->path, ': ', $message->text, PHP_EOL;
    }

    exit(1);
}

echo 'Saved: ', $entry->type->value, ' ', $entry->date->format('Y-m-d'), ' ', $entry->user->code, ' on ',
    $entry->project?->code ?? '-', ' / ', $entry->activity?->code ?? '-', PHP_EOL;

foreach ($entry->timeLines as $line) {
    echo '  ', $line->id, ' time ', $line->duration, ' at ', $line->rate->code, ': ', $line->internalValue,
        ' internal, ', $line->externalValue, ' external ', $line->currency,
        $line->billable ? ', billable' : '', PHP_EOL;
}

foreach ($entry->quantityLines as $line) {
    echo '  ', $line->id, ' quantity ', $line->quantity, ' at ', $line->rate->code, ': ', $line->internalValue,
        ' internal, ', $line->externalValue, ' external ', $line->currency,
        $line->billable ? ', billable' : '', PHP_EOL;
}
```

## Run

```sh
php examples/time-entries/create-time-entry/example.php JDOE P0099 A010
```

The write guard of the examples blocks changes unless you allow them for a company in `TWINFIELD_WRITE_COMPANIES`:

```sh
TWINFIELD_COMPANY=1002_3 TWINFIELD_ALLOW_WRITES=1002_3 php examples/time-entries/create-time-entry/example.php JDOE P0099 A010 --save
```

### Create/Update

Twinfield documentation: [Time entry: Create/Update](https://developers.twinfield.com/documentation/api/transaction-data/time/#createupdate).

```php
$twinfield->timeEntries()->save(
    TimeEntryInput::direct('JDOE', new DateTimeImmutable('2026-11-10'), 'P0099', 'A010')
        ->time(240, description: 'Deploy')
        ->quantity('1.5'),
);
```
