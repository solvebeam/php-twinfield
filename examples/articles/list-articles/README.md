# List articles

Lists the code and name of all articles of the company, or of the articles that match a pattern. Articles (items) belong to the Classic invoicing module: a sales invoice line refers to an article and one of its sub-articles.

<!-- twinfield-documentation:start -->
Twinfield documentation: [Articles](https://developers.twinfield.com/documentation/api/master-data/articles/).
<!-- twinfield-documentation:end -->

`search()` uses the Finder type `ART` and gives `ArticleSummary` results with `code` and `name`. `all()` fetches page after page while you iterate, so it also works for hundreds of articles. Use `get()` for the settings and the sub-articles (see [Read article](../read-article/)).

`articleVat(ArticleVat::Exclusive)` sends the Finder option `vat`. With that option Twinfield also returns its special items: `-` (free text), `0` (one-off item) and `T` (projects).

These are not the sales articles of the REST API: see [List sales articles](../../sales-articles/list-sales-articles/) for those.

## Code

```php
$twinfield = Example::twinfield();

foreach ($twinfield->articles()->search($pattern)->all() as $article) {
    echo $article->code, '  ', $article->name, PHP_EOL;
}
```

## Run

```sh
php examples/articles/list-articles/example.php
php examples/articles/list-articles/example.php 'BIKE*'
```

```text
5DISCOUNT  5% discount
BIKE  Bike summer edition
CONSULT  Consultancy
```

### Find

Twinfield documentation: [Articles: Find](https://developers.twinfield.com/documentation/api/master-data/articles/#find).

```php
$twinfield->articles()->search('*BIKE*')->limit(20)->get();
```

The SDK sends this in the SOAP body to `finder.asmx`, with SOAPAction `http://www.twinfield.com/Search`; the access token goes in the SOAP header:

```xml
<Search xmlns="http://www.twinfield.com/">
  <type>ART</type>
  <pattern>*BIKE*</pattern>
  <field>0</field>
  <firstRow>1</firstRow>
  <maxRows>20</maxRows>
</Search>
```

Twinfield answers with this SOAP body:

```xml
<SearchResponse xmlns="http://www.twinfield.com/">
  <SearchResult/>
  <data>
    <TotalRows>2</TotalRows>
    <Columns>
      <string>Code</string>
      <string>Naam</string>
    </Columns>
    <Items>
      <ArrayOfString>
        <string>5DISCOUNT</string>
        <string>5% discount</string>
      </ArrayOfString>
      <ArrayOfString>
        <string>BIKE</string>
        <string>Bike summer edition</string>
      </ArrayOfString>
    </Items>
  </data>
</SearchResponse>
```
