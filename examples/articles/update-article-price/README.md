# Update article price

> **This example changes data in Twinfield.** It creates an article first and deletes it again, but only run it on a test administration.

<!-- twinfield-documentation:start -->
Twinfield documentation: [Articles](https://developers.twinfield.com/documentation/api/master-data/articles/).
<!-- twinfield-documentation:end -->

Creates an example article, changes the price of its sub-article and adds a second sub-article.

An update sends the whole article. So start from `$article->edit()`: an `ArticleInput` with all current values and sub-articles, in which you only change what must change.

- `$subArticle->edit()` gives a `SubArticleInput` with the current values of a sub-article. `subArticle()` on the article input replaces the sub-article with the same code, or adds a new one.
- `removeSubArticle($code)` deletes a sub-article when the article is saved. Twinfield keeps a sub-article that is used in an invoice; adding it again with `subArticle()` recovers it.
- `unitPriceExcl()` clears the price including VAT, and the other way round: Twinfield calculates the other price with the VAT code.

`update()` throws an `ArticleNotFoundException` when the code does not exist, and reads the article back after saving.

## Code

```php
$twinfield = Example::twinfield();

$articles = $twinfield->articles();

$updated = $articles->update(
    $article->edit()
        ->subArticle($article->subArticles[0]->edit()->unitPriceExcl('799.00'))
        ->subArticle(SubArticleInput::create("Example man's bike", $account, $code . '-M')->unitPriceExcl('810.00')),
);
```

## Run

The write guard of the examples blocks changes unless you allow them for a company in `TWINFIELD_WRITE_COMPANIES`:

```sh
TWINFIELD_COMPANY=1002_3 TWINFIELD_ALLOW_WRITES=1002_3 php examples/articles/update-article-price/example.php
```

`composer test:write` also runs this example, after you confirm the company code.

```text
Created EXAMPLE999: EXAMPLE999-L 750.00
Updated EXAMPLE999-L: 799.00 excl., 966.79 incl.
Updated EXAMPLE999-M: 810.00 excl., 980.10 incl.
Deleted EXAMPLE999
```
