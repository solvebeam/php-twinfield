# Hierarchy access (700)

Browse code `700` (`BrowseCode::HierarchyAccess`, "Rapportagestructuurtoegang"): which users and roles have access to which reporting structure, and with which access type. See [Hierarchies](https://php-twinfield.solvebeam.com/guides/hierarchies/) for the reporting structures themselves.

<!-- twinfield-documentation:start -->
Twinfield documentation: [Browse data](https://developers.twinfield.com/documentation/api/request-data/browse-data/).
<!-- twinfield-documentation:end -->

- `hie.xss.type` is the access type: `none`, `use`, `link` or `edit`, and the only criterion.
- A row has a user (`hie.xss.user`) or a role (`hie.xss.role`).
- `hie.xss.hierarchyhidden` is `true` for a hidden reporting structure.

Criteria: access type. See [`browse-definitions/700.xml`](../../../browse-definitions/700.xml) and the [browse data guide](https://php-twinfield.solvebeam.com/guides/browse-data/).

## Code

```php
$twinfield = Example::twinfield();

$type = $argv[1] ?? null;

$query = $twinfield->browse(BrowseCode::HierarchyAccess)
    ->columns(
        'hie.xss.hierarchy',
        'hie.xss.hierarchyname',
        'hie.xss.hierarchyhidden',
        'hie.xss.role',
        'hie.xss.user',
        'hie.xss.type',
    );

if ($type !== null) {
    $query = $query->equal('hie.xss.type', $type);
}

$result = $query->get();

echo count($result), ' access right(s)', $type === null ? '' : ' of type ' . $type, PHP_EOL;

foreach ($result as $index => $row) {
    $user = $row->nullableString('hie.xss.user');

    echo sprintf(
        '[%d/%d] %s %s%s: %s %s',
        $index + 1,
        count($result),
        $row->string('hie.xss.hierarchy'),
        $row->nullableString('hie.xss.hierarchyname') ?? '',
        $row->string('hie.xss.hierarchyhidden') === 'true' ? ' (hidden)' : '',
        $user === null ? 'role ' . $row->string('hie.xss.role') : 'user ' . $user,
        $row->string('hie.xss.type'),
    ), PHP_EOL;
}
```

## Run

```sh
php examples/browse-data/700-hierarchy-access/example.php        # all access rights
php examples/browse-data/700-hierarchy-access/example.php edit   # only who can edit
```

Add `TWINFIELD_DEBUG=1` to see the SOAP requests and responses.

```text
2 access right(s)
[1/2] RS01 Example reporting structure: user EXAMPLE edit
[2/2] RS01 Example reporting structure: role LVL1 edit
```
