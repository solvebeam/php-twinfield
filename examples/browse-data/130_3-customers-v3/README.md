# Customers (130_3)

Browse code `130_3` (`BrowseCode::CustomersV3`, "Debiteuren (v3)"): the transaction lines of customers, like [130_2](../130_2-customers-v2/), with the credit manager of the customer, the collection run and the day book category. Use it for the open items per credit manager.

<!-- twinfield-documentation:start -->
Twinfield documentation: [Browse data](https://developers.twinfield.com/documentation/api/request-data/browse-data/).
<!-- twinfield-documentation:end -->

- `fin.trs.head.customer.respuser` and `respusername`: the credit manager of the customer.
- `fin.trs.line.payrun`: the collection run the line is in, empty when it is not in one.
- `like('fin.trs.head.typecategory', 'SALESINVOICE')`: the day book category is a `like` criterion, e.g. only sales invoices.
- `equal('fin.trs.line.matchstatus', 'available')`: open items.

Criteria: period, day book category, day book, status, change date of the transaction and of the line, general ledger account, customer, amount, open amount and payment status. See [`browse-definitions/130_3.xml`](../../../browse-definitions/130_3.xml) and the [browse data guide](https://php-twinfield.solvebeam.com/guides/browse-data/).

## Code

```php
$twinfield = Example::twinfield();

$year = Example::lastYear($twinfield);

$query = $twinfield->browse(BrowseCode::CustomersV3)
    ->columns(
        'fin.trs.head.customer.respuser',
        'fin.trs.head.customer.respusername',
        'fin.trs.line.dim2',
        'fin.trs.line.dim2name',
        'fin.trs.head.code',
        'fin.trs.head.number',
        'fin.trs.line.invnumber',
        'fin.trs.line.datedue',
        'fin.trs.line.openbasevaluesigned',
        'fin.trs.line.payrun',
    )
    ->between('fin.trs.head.yearperiod', '2000/00', sprintf('%d/55', $year))
    ->equal('fin.trs.head.status', 'normal')
    ->equal('fin.trs.line.matchstatus', 'available');

$result = $query->get();

echo count($result), ' open item(s)', PHP_EOL;

$perManager = [];

foreach ($result as $index => $row) {
    $manager = $row->nullableString('fin.trs.head.customer.respusername') ?? 'no credit manager';
    $due = $row->nullableDate('fin.trs.line.datedue');
    $open = $row->amount('fin.trs.line.openbasevaluesigned');
    $perManager[$manager] = ($perManager[$manager] ?? Amount::zero())->plus($open);
    $run = $row->nullableString('fin.trs.line.payrun');

    echo sprintf(
        '[%d/%d] %s: %s %s, %s %d invoice %s, due %s: open %s%s',
        $index + 1,
        count($result),
        $manager,
        $row->string('fin.trs.line.dim2'),
        $row->nullableString('fin.trs.line.dim2name') ?? '',
        $row->string('fin.trs.head.code'),
        $row->int('fin.trs.head.number'),
        $row->nullableString('fin.trs.line.invnumber') ?? '-',
        $due === null ? '-' : $due->format('Y-m-d'),
        $open,
        $run === null ? '' : ', collection run ' . $run,
    ), PHP_EOL;
}

foreach ($perManager as $manager => $open) {
    echo 'Open for ', $manager, ': ', $open, PHP_EOL;
}
```
