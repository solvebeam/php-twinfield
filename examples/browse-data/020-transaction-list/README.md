# Transaction list (020)

Browse code `020` (`BrowseCode::TransactionList`, "Invoerverslag"): the transaction lines as they were entered, per day book, with the input date and the user. Use it to check what was booked in a period, e.g. per day book or per user.

<!-- twinfield-documentation:start -->
Twinfield documentation: [Browse data](https://developers.twinfield.com/documentation/api/request-data/browse-data/).
<!-- twinfield-documentation:end -->

- `equal('fin.trs.head.code', $dayBook)`: one day book. `equal('fin.trs.head.typecategory', 'SALESINVOICE')` selects all day books of a category.
- `equal('fin.trs.head.status', 'normal')`: provisional and final. Without it you also get drafts, with number `-1`.
- `fin.trs.head.inpdate` is when the transaction was entered, a `Datetime`: `dateTime()`. It is also a criterion, like `fin.trs.head.modified` and `fin.trs.head.user`.
- `fin.trs.head.browseregime` is the regime of the transaction (`Generic`, `Fiscal`, …) and can be a criterion.

Criteria: period, day book category, day book, number, status, date, input date, change date, the three dimensions, amount, invoice number, user and regime. See [`browse-definitions/020.xml`](../../../browse-definitions/020.xml) and the [browse data guide](https://php-twinfield.solvebeam.com/guides/browse-data/).

## Code

```php
$twinfield = Example::twinfield();

$year = (int) ($argv[1] ?? Example::lastYear($twinfield));
$dayBook = $argv[2] ?? null;

$query = $twinfield->browse(BrowseCode::TransactionList)
    ->columns(
        'fin.trs.head.code',
        'fin.trs.head.number',
        'fin.trs.head.status',
        'fin.trs.head.date',
        'fin.trs.head.inpdate',
        'fin.trs.line.dim1',
        'fin.trs.line.dim2',
        'fin.trs.line.basevaluesigned',
        'fin.trs.line.description',
    )
    ->between('fin.trs.head.yearperiod', sprintf('%d/00', $year), sprintf('%d/55', $year))
    ->equal('fin.trs.head.status', 'normal');

if ($dayBook !== null) {
    $query = $query->equal('fin.trs.head.code', $dayBook);
}

$result = $query->get();

echo count($result), ' transaction line(s) entered in ', $year;
echo $dayBook === null ? '' : ' in day book ' . $dayBook, PHP_EOL;

foreach ($result as $index => $row) {
    echo rtrim(sprintf(
        '[%d/%d] %s %d line %d (%s), %s, entered %s: %s %s %s %s',
        $index + 1,
        count($result),
        $row->string('fin.trs.head.code'),
        $row->int('fin.trs.head.number'),
        $row->transactionLine?->line,
        $row->displayName('fin.trs.head.status') ?? $row->string('fin.trs.head.status'),
        $row->date('fin.trs.head.date')->format('Y-m-d'),
        $row->dateTime('fin.trs.head.inpdate')->format('Y-m-d H:i'),
        $row->string('fin.trs.line.dim1'),
        $row->nullableString('fin.trs.line.dim2') ?? '-',
        $row->amount('fin.trs.line.basevaluesigned'),
        $row->nullableString('fin.trs.line.description') ?? '',
    )), PHP_EOL;
}
```

## Run

```sh
php examples/browse-data/020-transaction-list/example.php            # the last year
php examples/browse-data/020-transaction-list/example.php 2026 VRK   # day book VRK in 2026
```
