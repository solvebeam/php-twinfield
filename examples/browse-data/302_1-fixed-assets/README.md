# Fixed assets (302_1)

Browse code `302_1` (`BrowseCode::FixedAssets`, "Activa"): the transaction lines of fixed assets with the depreciation settings of the asset: the year and period the depreciation starts and the term in periods.

<!-- twinfield-documentation:start -->
Twinfield documentation: [Browse data](https://developers.twinfield.com/documentation/api/request-data/browse-data/).
<!-- twinfield-documentation:end -->

- `fin.trs.line.asset.beginyear`, `beginperiod` and `depreciationterm` are numbers: `int()`.
- `between('fin.trs.line.dim3', $asset, $asset)`: one asset. The day book can be a criterion as well, e.g. the depreciation day book.
- For the fixed assets themselves (not their transactions) see [Fixed assets](https://php-twinfield.solvebeam.com/guides/fixed-assets/).

Criteria: period, day book, status and asset. See [`browse-definitions/302_1.xml`](../../../browse-definitions/302_1.xml) and the [browse data guide](https://php-twinfield.solvebeam.com/guides/browse-data/).

## Code

```php
$twinfield = Example::twinfield();

$year = (int) ($argv[1] ?? Example::lastYear($twinfield));

$query = $twinfield->browse(BrowseCode::FixedAssets)
    ->columns(
        'fin.trs.line.dim3',
        'fin.trs.line.dim3name',
        'fin.trs.line.asset.beginyear',
        'fin.trs.line.asset.beginperiod',
        'fin.trs.line.asset.depreciationterm',
        'fin.trs.head.code',
        'fin.trs.head.number',
        'fin.trs.line.dim1',
        'fin.trs.line.basevaluesigned',
    )
    ->between('fin.trs.head.yearperiod', sprintf('%d/00', $year), sprintf('%d/55', $year))
    ->equal('fin.trs.head.status', 'normal');

$result = $query->get();

echo count($result), ' fixed asset line(s) in ', $year, PHP_EOL;

foreach ($result as $index => $row) {
    echo sprintf(
        '[%d/%d] %s %s (from %d/%02d, %d periods): %s %d %s %s',
        $index + 1,
        count($result),
        $row->string('fin.trs.line.dim3'),
        $row->nullableString('fin.trs.line.dim3name') ?? '',
        $row->int('fin.trs.line.asset.beginyear'),
        $row->int('fin.trs.line.asset.beginperiod'),
        $row->int('fin.trs.line.asset.depreciationterm'),
        $row->string('fin.trs.head.code'),
        $row->int('fin.trs.head.number'),
        $row->string('fin.trs.line.dim1'),
        $row->amount('fin.trs.line.basevaluesigned'),
    ), PHP_EOL;
}
```
