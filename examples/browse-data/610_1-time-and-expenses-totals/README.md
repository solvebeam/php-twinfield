# Time & Expenses totals (610_1)

Browse code `610_1` (`BrowseCode::TimeAndExpensesTotals`, "Uren en onkosten (Totalen)"): the totals of time, expenses and quantities in Time & Expenses per project, activity, rate and user, with the internal and external amount.

<!-- twinfield-documentation:start -->
Twinfield documentation: [Browse data](https://developers.twinfield.com/documentation/api/request-data/browse-data/).
<!-- twinfield-documentation:end -->

- `betweenDates('teq.trs.head.date', $from, $to)`: the date is a criterion only.
- `teq.trs.line.type` is `time`, `expense` or `quantity`; `teq.trs.line.billable` is `true` or `false`.
- `teq.trs.head.project1` is the project and `project2` the activity.
- Time & Expenses is a separate module of Twinfield: a company without it gives no rows.

Criteria: date, project, activity and user. See [`browse-definitions/610_1.xml`](../../../browse-definitions/610_1.xml) and the [browse data guide](https://php-twinfield.solvebeam.com/guides/browse-data/).

## Code

```php
$twinfield = Example::twinfield();

$year = (int) ($argv[1] ?? Example::lastYear($twinfield));
$from = new DateTimeImmutable($year . '-01-01');
$to = new DateTimeImmutable($year . '-12-31');

$query = $twinfield->browse(BrowseCode::TimeAndExpensesTotals)
    ->columns(
        'teq.trs.head.project1',
        'teq.trs.head.project2',
        'teq.trs.head.user',
        'teq.trs.line.type',
        'teq.trs.line.rate.code',
        'teq.trs.line.billable',
        'teq.trs.line.quantity',
        'teq.trs.line.valueint',
        'teq.trs.line.valueext',
    )
    ->betweenDates('teq.trs.head.date', $from, $to);

$result = $query->get();

echo count($result), ' row(s) from ', $from->format('Y-m-d'), ' to ', $to->format('Y-m-d'), PHP_EOL;

foreach ($result as $index => $row) {
    echo sprintf(
        '[%d/%d] project %s activity %s, %s, %s rate %s%s: %s, internal %s, external %s',
        $index + 1,
        count($result),
        $row->string('teq.trs.head.project1'),
        $row->nullableString('teq.trs.head.project2') ?? '-',
        $row->string('teq.trs.head.user'),
        $row->string('teq.trs.line.type'),
        $row->nullableString('teq.trs.line.rate.code') ?? '-',
        $row->string('teq.trs.line.billable') === 'true' ? ' (billable)' : '',
        $row->nullableDecimal('teq.trs.line.quantity') ?? '0',
        $row->amount('teq.trs.line.valueint'),
        $row->amount('teq.trs.line.valueext'),
    ), PHP_EOL;
}
```
