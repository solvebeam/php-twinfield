# General ledger intercompany (031)

Browse code `031` (`BrowseCode::GeneralLedgerIntercompany`, "Grootboek (rekening-courant)"): the transaction lines of intercompany transactions, with the company and general ledger account on the other side (the destination). Use it to reconcile the intercompany accounts of companies in one organisation.

<!-- twinfield-documentation:start -->
Twinfield documentation: [Browse data](https://developers.twinfield.com/documentation/api/request-data/browse-data/).
<!-- twinfield-documentation:end -->

- `fin.trs.line.destination.officename`, `destination.dim1` and `destination.dim1name`: the company and account the line was booked against. `destination.dim2name` and `destination.dim3name` have the names of the other dimensions.
- Only intercompany transactions are returned: a company without them gives no rows.
- `between('fin.trs.head.yearperiod', $from, $to)`: the period can only be a criterion.

Criteria: period, status, the three dimensions and regime. See [`browse-definitions/031.xml`](../../../browse-definitions/031.xml) and the [browse data guide](https://php.twinfield.solvebeam.com/guides/browse-data/).

## Code

```php
$twinfield = Example::twinfield();

$year = (int) ($argv[1] ?? Example::lastYear($twinfield));

$query = $twinfield->browse(BrowseCode::GeneralLedgerIntercompany)
    ->columns(
        'fin.trs.head.code',
        'fin.trs.head.number',
        'fin.trs.head.date',
        'fin.trs.line.dim1',
        'fin.trs.line.valuesigned',
        'fin.trs.line.destination.officename',
        'fin.trs.line.destination.dim1',
        'fin.trs.line.destination.dim1name',
    )
    ->between('fin.trs.head.yearperiod', sprintf('%d/00', $year), sprintf('%d/55', $year))
    ->equal('fin.trs.head.status', 'normal');

$result = $query->get();

echo count($result), ' intercompany line(s) in ', $year, PHP_EOL;

foreach ($result as $index => $row) {
    echo rtrim(sprintf(
        '[%d/%d] %s %d line %d, %s: %s %s, other side %s %s %s',
        $index + 1,
        count($result),
        $row->string('fin.trs.head.code'),
        $row->int('fin.trs.head.number'),
        $row->transactionLine?->line,
        $row->date('fin.trs.head.date')->format('Y-m-d'),
        $row->string('fin.trs.line.dim1'),
        $row->amount('fin.trs.line.valuesigned'),
        $row->nullableString('fin.trs.line.destination.officename') ?? '-',
        $row->nullableString('fin.trs.line.destination.dim1') ?? '-',
        $row->nullableString('fin.trs.line.destination.dim1name') ?? '',
    )), PHP_EOL;
}
```
