# Suppliers (230_1)

Browse code `230_1` (`BrowseCode::Suppliers`, "Crediteuren"): the transaction lines of suppliers with their payment status and due date. [200](../200-supplier-transactions/) has fewer fields; [230_2](../230_2-suppliers-v2/) has more criteria.

<!-- twinfield-documentation:start -->
Twinfield documentation: [Browse data](https://developers.twinfield.com/documentation/api/request-data/browse-data/).
<!-- twinfield-documentation:end -->

- `equal('fin.trs.line.matchstatus', 'available')`: open items, the invoices still to pay. `matched` gives the paid items.
- Amounts of supplier invoices are negative (credit).
- `like('fin.trs.head.code', 'INK*')`: the day book is a `like` criterion in 230_1.

Criteria: period, day book, status, general ledger account, supplier and payment status. See [`browse-definitions/230_1.xml`](../../../browse-definitions/230_1.xml) and the [browse data guide](https://php-twinfield.solvebeam.com/guides/browse-data/).

## Code

```php
$twinfield = Example::twinfield();

$year = Example::lastYear($twinfield);
$supplier = $argv[1] ?? null;

$query = $twinfield->browse(BrowseCode::Suppliers)
    ->columns(
        'fin.trs.line.dim2',
        'fin.trs.line.dim2name',
        'fin.trs.head.code',
        'fin.trs.head.number',
        'fin.trs.line.invnumber',
        'fin.trs.line.datedue',
        'fin.trs.line.basevaluesigned',
        'fin.trs.line.openbasevaluesigned',
        'fin.trs.line.matchstatus',
    )
    ->between('fin.trs.head.yearperiod', '2000/00', sprintf('%d/55', $year))
    ->equal('fin.trs.head.status', 'normal')
    ->equal('fin.trs.line.matchstatus', 'available');

if ($supplier !== null) {
    $query = $query->between('fin.trs.line.dim2', $supplier, $supplier);
}

$result = $query->get();

echo count($result), ' open item(s)', $supplier === null ? '' : ' of supplier ' . $supplier, PHP_EOL;

$open = Amount::zero();

foreach ($result as $index => $row) {
    $due = $row->nullableDate('fin.trs.line.datedue');
    $open = $open->plus($row->amount('fin.trs.line.openbasevaluesigned'));

    echo sprintf(
        '[%d/%d] %s %s, %s %d invoice %s, due %s: %s, open %s',
        $index + 1,
        count($result),
        $row->string('fin.trs.line.dim2'),
        $row->nullableString('fin.trs.line.dim2name') ?? '',
        $row->string('fin.trs.head.code'),
        $row->int('fin.trs.head.number'),
        $row->nullableString('fin.trs.line.invnumber') ?? '-',
        $due === null ? '-' : $due->format('Y-m-d'),
        $row->amount('fin.trs.line.basevaluesigned'),
        $row->amount('fin.trs.line.openbasevaluesigned'),
    ), PHP_EOL;
}

echo 'Total open: ', $open, PHP_EOL;
```
