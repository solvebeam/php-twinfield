# Time & Expenses billing per week (661_1)

Browse code `661_1` (`BrowseCode::TimeAndExpensesBillingPerWeek`, "Uren en onkosten (Facturatie per week)"): the external value of the Time & Expenses entries and the amount proposed for billing, summed per week. Compare both to see what is not billed yet.

<!-- twinfield-documentation:start -->
Twinfield documentation: [Browse data](https://developers.twinfield.com/documentation/api/request-data/browse-data/).
<!-- twinfield-documentation:end -->

- `teq.trs.head.year` and `teq.trs.head.week` as columns give one row per week; add `customer` or `project1` to split them further.
- `teq.trs.line.valueext` is the external value, `ivb.trs.line.value` the amount in invoice proposals.
- `betweenDates('teq.trs.head.date', $from, $to)`: the date is a criterion only.
- Time & Expenses is a separate module of Twinfield: a company without it gives no rows.

Criteria: year/week, date, user, cost centre of the user, hour code, authoriser, customer, project, cost centre of the project and activity. See [`browse-definitions/661_1.xml`](../../../browse-definitions/661_1.xml) and the [browse data guide](https://php-twinfield.solvebeam.com/guides/browse-data/).

## Code

```php
$twinfield = Example::twinfield();

$year = (int) ($argv[1] ?? Example::lastYear($twinfield));
$from = new DateTimeImmutable($year . '-01-01');
$to = new DateTimeImmutable($year . '-12-31');

$query = $twinfield->browse(BrowseCode::TimeAndExpensesBillingPerWeek)
    ->columns(
        'teq.trs.head.year',
        'teq.trs.head.week',
        'teq.trs.head.customer',
        'teq.trs.head.project1',
        'teq.trs.line.quantity',
        'teq.trs.line.valueext',
        'ivb.trs.line.value',
    )
    ->betweenDates('teq.trs.head.date', $from, $to);

$result = $query->get();

echo count($result), ' row(s) from ', $from->format('Y-m-d'), ' to ', $to->format('Y-m-d'), PHP_EOL;

foreach ($result as $index => $row) {
    echo sprintf(
        '[%d/%d] %d week %d, customer %s, project %s: quantity %s, value %s, proposed %s',
        $index + 1,
        count($result),
        $row->int('teq.trs.head.year'),
        $row->int('teq.trs.head.week'),
        $row->nullableString('teq.trs.head.customer') ?? '-',
        $row->string('teq.trs.head.project1'),
        $row->nullableDecimal('teq.trs.line.quantity') ?? '0',
        $row->amount('teq.trs.line.valueext'),
        $row->amount('ivb.trs.line.value'),
    ), PHP_EOL;
}
```
