# General ledger details (030_1)

Browse code `030_1` (`BrowseCode::GeneralLedgerDetails`, "Grootboek (details)"): every transaction line with its details, such as the dimension names and types, the VAT code and the origin. It is the first version of [030_3](../030_3-general-ledger-details/), which has more fields; use 030_3 for new code.

<!-- twinfield-documentation:start -->
Twinfield documentation: [Browse data](https://developers.twinfield.com/documentation/api/request-data/browse-data/).
<!-- twinfield-documentation:end -->

- `between('fin.trs.head.yearperiod', $from, $to)`: the period can only be a criterion. Use `fin.trs.head.year` and `fin.trs.head.period` as columns.
- `equal('fin.trs.head.status', 'normal')`: provisional and final.
- `fin.trs.line.dim1type` is the dimension type of the account, e.g. `BAS` or `PNL`; `fin.trs.line.dim2type` and `dim3type` tell what is in `dim2` and `dim3` (`DEB`, `CRD`, `KPL`, `PRJ`, …).
- `fin.trs.head.origin` is how the transaction was made (e.g. `import`), with the display name in `displayName()`.

Criteria: period, status, input date, change date and the three dimensions. See [`browse-definitions/030_1.xml`](../../../browse-definitions/030_1.xml) and the [browse data guide](https://php.twinfield.solvebeam.com/guides/browse-data/).

## Code

```php
$twinfield = Example::twinfield();

$year = (int) ($argv[1] ?? Example::lastYear($twinfield));

$query = $twinfield->browse(BrowseCode::GeneralLedgerDetails)
    ->columns(
        'fin.trs.head.code',
        'fin.trs.head.number',
        'fin.trs.head.date',
        'fin.trs.head.origin',
        'fin.trs.line.dim1',
        'fin.trs.line.dim1type',
        'fin.trs.line.dim2',
        'fin.trs.line.dim2type',
        'fin.trs.line.debitcredit',
        'fin.trs.line.valuesigned',
        'fin.trs.line.vatcode',
    )
    ->between('fin.trs.head.yearperiod', sprintf('%d/00', $year), sprintf('%d/55', $year))
    ->equal('fin.trs.head.status', 'normal');

$result = $query->get();

echo count($result), ' transaction line(s) in ', $year, PHP_EOL;

foreach ($result as $index => $row) {
    $dim2 = $row->nullableString('fin.trs.line.dim2');

    echo sprintf(
        '[%d/%d] %s %d line %d, %s, %s: %s (%s) %s %s %s%s',
        $index + 1,
        count($result),
        $row->string('fin.trs.head.code'),
        $row->int('fin.trs.head.number'),
        $row->transactionLine?->line,
        $row->date('fin.trs.head.date')->format('Y-m-d'),
        $row->displayName('fin.trs.head.origin') ?? $row->string('fin.trs.head.origin'),
        $row->string('fin.trs.line.dim1'),
        $row->string('fin.trs.line.dim1type'),
        $dim2 === null ? '-' : $dim2 . ' (' . $row->string('fin.trs.line.dim2type') . ')',
        $row->string('fin.trs.line.debitcredit'),
        $row->amount('fin.trs.line.valuesigned'),
        $row->nullableString('fin.trs.line.vatcode') === null ? '' : ' VAT ' . $row->string('fin.trs.line.vatcode'),
    ), PHP_EOL;
}
```
