# Time & Expenses multicurrency (620)

Browse code `620` (`BrowseCode::TimeAndExpensesMulticurrency`, "Uren en onkosten (MC)"): totals of the general ledger per project, cost centre and account, in the currency of the transactions and in the base currency.

<!-- twinfield-documentation:start -->
Twinfield documentation: [Browse data](https://developers.twinfield.com/documentation/api/request-data/browse-data/).
<!-- twinfield-documentation:end -->

- Despite its name, 620 reads the general ledger (`fin.trs.*`), not the Time & Expenses entries: it gives the booked amounts per project (`dim3`).
- `fin.trs.head.curcode` with `fin.trs.line.valuesigned`: the total in the currency of the transactions; `basevaluesigned` in the base currency.
- The rows are totals: `$row->transactionLine` is null.

Criteria: period, the three dimensions and status. See [`browse-definitions/620.xml`](../../../browse-definitions/620.xml) and the [browse data guide](https://php-twinfield.solvebeam.com/guides/browse-data/).

## Code

```php
$twinfield = Example::twinfield();

$year = (int) ($argv[1] ?? Example::lastYear($twinfield));

$query = $twinfield->browse(BrowseCode::TimeAndExpensesMulticurrency)
    ->columns(
        'fin.trs.line.dim3',
        'fin.trs.line.dim3name',
        'fin.trs.line.dim2',
        'fin.trs.line.dim1',
        'fin.trs.head.curcode',
        'fin.trs.line.valuesigned',
        'fin.trs.line.basevaluesigned',
    )
    ->between('fin.trs.head.yearperiod', sprintf('%d/00', $year), sprintf('%d/55', $year))
    ->equal('fin.trs.head.status', 'normal');

$result = $query->get();

echo count($result), ' total(s) per project in ', $year, PHP_EOL;

foreach ($result as $index => $row) {
    echo sprintf(
        '[%d/%d] project %s %s, cost centre %s, account %s: %s %s (base %s)',
        $index + 1,
        count($result),
        $row->nullableString('fin.trs.line.dim3') ?? '-',
        $row->nullableString('fin.trs.line.dim3name') ?? '',
        $row->nullableString('fin.trs.line.dim2') ?? '-',
        $row->string('fin.trs.line.dim1'),
        $row->string('fin.trs.head.curcode'),
        $row->amount('fin.trs.line.valuesigned'),
        $row->amount('fin.trs.line.basevaluesigned'),
    ), PHP_EOL;
}
```
