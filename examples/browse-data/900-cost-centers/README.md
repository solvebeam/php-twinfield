# Cost centers (900)

Browse code `900` (`BrowseCode::CostCenters`, "Kostenplaatsen"): the transaction lines booked on cost centres (dimension 2), with the general ledger account.

<!-- twinfield-documentation:start -->
Twinfield documentation: [Browse data](https://developers.twinfield.com/documentation/api/request-data/browse-data/).
<!-- twinfield-documentation:end -->

- `fin.trs.line.dim2` is the cost centre and `dim1` the general ledger account.
- `between('fin.trs.line.dim2', $from, $to)`: a range of cost centres.
- `equal('fin.trs.head.browseregime', $regime)`: the regime. The status is not a criterion in 900: you get all transactions, also drafts (number `-1`).

Criteria: period, general ledger account, cost centre, day book, number and regime. See [`browse-definitions/900.xml`](../../../browse-definitions/900.xml) and the [browse data guide](https://php-twinfield.solvebeam.com/guides/browse-data/).

## Code

```php
$twinfield = Example::twinfield();

$year = (int) ($argv[1] ?? Example::lastYear($twinfield));

$query = $twinfield->browse(BrowseCode::CostCenters)
    ->columns(
        'fin.trs.line.dim2',
        'fin.trs.line.dim2name',
        'fin.trs.line.dim1',
        'fin.trs.line.dim1name',
        'fin.trs.head.code',
        'fin.trs.head.number',
        'fin.trs.line.basevaluesigned',
    )
    ->between('fin.trs.head.yearperiod', sprintf('%d/00', $year), sprintf('%d/55', $year));

$result = $query->get();

echo count($result), ' cost centre line(s) in ', $year, PHP_EOL;

$totals = [];

foreach ($result as $index => $row) {
    $costCenter = $row->string('fin.trs.line.dim2');
    $value = $row->amount('fin.trs.line.basevaluesigned');
    $totals[$costCenter] = ($totals[$costCenter] ?? Amount::zero())->plus($value);

    echo sprintf(
        '[%d/%d] %s %s: %s %s, %s %d %s',
        $index + 1,
        count($result),
        $costCenter,
        $row->nullableString('fin.trs.line.dim2name') ?? '',
        $row->string('fin.trs.line.dim1'),
        $row->nullableString('fin.trs.line.dim1name') ?? '',
        $row->string('fin.trs.head.code'),
        $row->int('fin.trs.head.number'),
        $value,
    ), PHP_EOL;
}

foreach ($totals as $costCenter => $total) {
    echo 'Total ', $costCenter, ': ', $total, PHP_EOL;
}
```
