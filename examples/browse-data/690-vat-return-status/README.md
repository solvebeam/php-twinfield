# VAT return status (690)

Browse code `690` (`BrowseCode::VatReturnStatus`, "Btw-aangifte status"): the VAT and ICT returns of a year with their period, status and when they were sent. The returns themselves are in [Declarations](https://php-twinfield.solvebeam.com/guides/declarations/).

<!-- twinfield-documentation:start -->
Twinfield documentation: [Browse data](https://developers.twinfield.com/documentation/api/request-data/browse-data/).
<!-- twinfield-documentation:end -->

- `equal('fin.vat.declyear', $year)`: the returns of one year. `equal('fin.vat.statusname', 'sent')` selects on the status.
- `fin.vat.decltype`: `vat`, `ict`, `taxgroup`, `yearlysuppletion` or `taxgroupyearlysuppletion`; `fin.vat.timeframe` the period of the return, e.g. `quarter1`.
- `fin.vat.statusname` is the status (`created`, `authorised`, `sent`, `approved`, `rejected`, …); `fin.vat.status` the status code.
- `fin.vat.sent` is a `Datetime`, empty when the return is not sent yet.

Criteria: year and status. See [`browse-definitions/690.xml`](../../../browse-definitions/690.xml) and the [browse data guide](https://php-twinfield.solvebeam.com/guides/browse-data/).

## Code

```php
$twinfield = Example::twinfield();

$year = (int) ($argv[1] ?? date('Y'));

$query = $twinfield->browse(BrowseCode::VatReturnStatus)
    ->columns(
        'fin.vat.decltype',
        'fin.vat.declyear',
        'fin.vat.timeframe',
        'fin.vat.statusname',
        'fin.vat.sent',
    )
    ->equal('fin.vat.declyear', $year);

$result = $query->get();

echo count($result), ' return(s) in ', $year, PHP_EOL;

foreach ($result as $index => $row) {
    $sent = $row->nullableString('fin.vat.sent') === null ? null : $row->dateTime('fin.vat.sent');

    echo sprintf(
        '[%d/%d] %s %d %s: %s%s',
        $index + 1,
        count($result),
        $row->string('fin.vat.decltype'),
        $row->int('fin.vat.declyear'),
        $row->displayName('fin.vat.timeframe') ?? $row->string('fin.vat.timeframe'),
        $row->string('fin.vat.statusname'),
        $sent === null ? '' : ', sent ' . $sent->format('Y-m-d H:i'),
    ), PHP_EOL;
}
```
