# General ledger details (030_2)

Browse code `030_2` (`BrowseCode::GeneralLedgerDetailsV2`, "Grootboek (details) (v2)"): every transaction line with its details. Compared with 030_1 it has the relation of the transaction and the regime. [030_3](../030_3-general-ledger-details/) has more fields; use that one for new code.

<!-- twinfield-documentation:start -->
Twinfield documentation: [Browse data](https://developers.twinfield.com/documentation/api/request-data/browse-data/).
<!-- twinfield-documentation:end -->

- `fin.trs.head.relation` and `fin.trs.head.relationname`: the customer or supplier of the transaction, also on the lines that have no relation in `dim2`.
- `equal('fin.trs.head.regime', $regime)`: `Fiscal`, `Commercial` or `Economic` give the lines of that regime plus the generic lines; `Generic` only the generic lines. See [Regimes](https://php-twinfield.solvebeam.com/guides/browse-data/#regimes).
- `between('fin.trs.head.yearperiod', $from, $to)`: the period can only be a criterion.

Criteria: period, status, input date, change date, the three dimensions and regime. See [`browse-definitions/030_2.xml`](../../../browse-definitions/030_2.xml) and the [browse data guide](https://php-twinfield.solvebeam.com/guides/browse-data/).

## Code

```php
$twinfield = Example::twinfield();

$year = (int) ($argv[1] ?? Example::lastYear($twinfield));
$regime = isset($argv[2]) ? Regime::from($argv[2]) : null;

$query = $twinfield->browse(BrowseCode::GeneralLedgerDetailsV2)
    ->columns(
        'fin.trs.head.code',
        'fin.trs.head.number',
        'fin.trs.head.relation',
        'fin.trs.head.relationname',
        'fin.trs.line.dim1',
        'fin.trs.line.dim2',
        'fin.trs.line.valuesigned',
        'fin.trs.head.regime',
    )
    ->between('fin.trs.head.yearperiod', sprintf('%d/00', $year), sprintf('%d/55', $year))
    ->equal('fin.trs.head.status', 'normal');

if ($regime !== null) {
    $query = $query->equal('fin.trs.head.regime', $regime);
}

$result = $query->get();

echo count($result), ' transaction line(s) in ', $year, $regime === null ? '' : ', regime ' . $regime->value, PHP_EOL;

foreach ($result as $index => $row) {
    $relation = $row->nullableString('fin.trs.head.relation');

    echo sprintf(
        '[%d/%d] %s %d line %d (%s), relation %s: %s %s %s',
        $index + 1,
        count($result),
        $row->string('fin.trs.head.code'),
        $row->int('fin.trs.head.number'),
        $row->transactionLine?->line,
        $row->string('fin.trs.head.regime'),
        $relation === null ? '-' : $relation . ' ' . ($row->nullableString('fin.trs.head.relationname') ?? ''),
        $row->string('fin.trs.line.dim1'),
        $row->nullableString('fin.trs.line.dim2') ?? '-',
        $row->amount('fin.trs.line.valuesigned'),
    ), PHP_EOL;
}
```

## Run

```sh
php examples/browse-data/030_2-general-ledger-details-v2/example.php               # the last year, all regimes
php examples/browse-data/030_2-general-ledger-details-v2/example.php 2026 Fiscal   # the fiscal and generic lines of 2026
```
