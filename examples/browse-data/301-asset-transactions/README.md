# Asset transactions (301)

Browse code `301` (`BrowseCode::AssetTransactions`, "Activakaart"): the transaction lines booked on fixed assets (dimension 3), such as the purchase and the depreciation. [302_1](../302_1-fixed-assets/) has the depreciation settings of the assets as well.

<!-- twinfield-documentation:start -->
Twinfield documentation: [Browse data](https://developers.twinfield.com/documentation/api/request-data/browse-data/).
<!-- twinfield-documentation:end -->

- `fin.trs.line.dim3` is the fixed asset, `dim1` the general ledger account and `dim2` the cost centre.
- `between('fin.trs.line.dim3', $asset, $asset)`: one asset.
- The status is not a criterion in 301: you get all transactions, also drafts (number `-1`).

Criteria: period, the three dimensions, day book and number. See [`browse-definitions/301.xml`](../../../browse-definitions/301.xml) and the [browse data guide](https://php.twinfield.solvebeam.com/guides/browse-data/).

## Code

```php
$twinfield = Example::twinfield();

$year = (int) ($argv[1] ?? Example::lastYear($twinfield));
$asset = $argv[2] ?? null;

$query = $twinfield->browse(BrowseCode::AssetTransactions)
    ->columns(
        'fin.trs.line.dim3',
        'fin.trs.line.dim3name',
        'fin.trs.head.code',
        'fin.trs.head.number',
        'fin.trs.line.dim1',
        'fin.trs.line.dim1name',
        'fin.trs.line.basevaluesigned',
    )
    ->between('fin.trs.head.yearperiod', sprintf('%d/00', $year), sprintf('%d/55', $year));

if ($asset !== null) {
    $query = $query->between('fin.trs.line.dim3', $asset, $asset);
}

$result = $query->get();

echo count($result), ' asset line(s) in ', $year, $asset === null ? '' : ' of asset ' . $asset, PHP_EOL;

foreach ($result as $index => $row) {
    echo sprintf(
        '[%d/%d] %s %s, %s %d: %s %s %s',
        $index + 1,
        count($result),
        $row->string('fin.trs.line.dim3'),
        $row->nullableString('fin.trs.line.dim3name') ?? '',
        $row->string('fin.trs.head.code'),
        $row->int('fin.trs.head.number'),
        $row->string('fin.trs.line.dim1'),
        $row->nullableString('fin.trs.line.dim1name') ?? '',
        $row->amount('fin.trs.line.basevaluesigned'),
    ), PHP_EOL;
}
```

## Run

```sh
php examples/browse-data/301-asset-transactions/example.php              # the last year
php examples/browse-data/301-asset-transactions/example.php 2026 A0001   # asset A0001 in 2026
```
