# Bank link details (680)

Browse code `680` (`BrowseCode::BankLinkDetails`, "Bankkoppeling details"): the bank books of the company with their IBAN, general ledger account and the status of the bank link. [680_2](../680_2-bank-link-details-v2/) has more details.

<!-- twinfield-documentation:start -->
Twinfield documentation: [Browse data](https://developers.twinfield.com/documentation/api/request-data/browse-data/).
<!-- twinfield-documentation:end -->

- `fin.bnk.transactiontype` is the bank book (day book) and the only criterion.
- `fin.bnk.banklinkstatus`: `none`, `pending` or `active`.
- A bank book without IBAN has `-` in `fin.bnk.iban`.
- The rows are not transactions: `$row->transactionLine` is null.

Criteria: bank book. See [`browse-definitions/680.xml`](../../../browse-definitions/680.xml) and the [browse data guide](https://php.twinfield.solvebeam.com/guides/browse-data/).

## Code

```php
$twinfield = Example::twinfield();

$query = $twinfield->browse(BrowseCode::BankLinkDetails)
    ->columns(
        'fin.bnk.transactiontype',
        'fin.bnk.iban',
        'fin.bnk.dim1',
        'fin.bnk.dim1name',
        'fin.bnk.banklinkstatus',
    );

$result = $query->get();

echo count($result), ' bank book(s)', PHP_EOL;

foreach ($result as $index => $row) {
    $account = $row->nullableString('fin.bnk.dim1');

    echo sprintf(
        '[%d/%d] %s IBAN %s, account %s: bank link %s',
        $index + 1,
        count($result),
        $row->string('fin.bnk.transactiontype'),
        $row->string('fin.bnk.iban'),
        $account === null ? '-' : $account . ' ' . ($row->nullableString('fin.bnk.dim1name') ?? ''),
        $row->string('fin.bnk.banklinkstatus'),
    ), PHP_EOL;
}
```
