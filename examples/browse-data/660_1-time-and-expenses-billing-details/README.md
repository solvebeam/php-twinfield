# Time & Expenses billing details (660_1)

Browse code `660_1` (`BrowseCode::TimeAndExpensesBillingDetails`, "Uren en onkosten (Facturatiedetails)"): the Time & Expenses entries with the invoice proposal and the invoice they were billed on, and the proposed quantity and amount.

<!-- twinfield-documentation:start -->
Twinfield documentation: [Browse data](https://developers.twinfield.com/documentation/api/request-data/browse-data/).
<!-- twinfield-documentation:end -->

- `ivb.trs.head.number` is the invoice proposal, `inv.trs.head.number` the invoice; both are numbers and empty when the entry is not billed yet.
- `ivb.trs.line.source`: what the line bills, e.g. `time`, `expenses`, `quantities` or `postponed`.
- `ivb.trs.line.value` is the proposed amount, `teq.trs.line.valueext` the external value of the entry.
- Time & Expenses is a separate module of Twinfield: a company without it gives no rows.

Criteria: year/month, year/week, date, user, cost centre of the user, hour code, authoriser, customer, project, cost centre of the project and activity. See [`browse-definitions/660_1.xml`](../../../browse-definitions/660_1.xml) and the [browse data guide](https://php-twinfield.solvebeam.com/guides/browse-data/).

## Code

```php
$twinfield = Example::twinfield();

$year = (int) ($argv[1] ?? Example::lastYear($twinfield));
$from = new DateTimeImmutable($year . '-01-01');
$to = new DateTimeImmutable($year . '-12-31');

$query = $twinfield->browse(BrowseCode::TimeAndExpensesBillingDetails)
    ->columns(
        'teq.trs.head.date',
        'teq.trs.head.customer',
        'teq.trs.head.project1',
        'ivb.trs.head.number',
        'ivb.trs.line.source',
        'inv.trs.head.number',
        'teq.trs.line.valueext',
        'ivb.trs.line.value',
    )
    ->betweenDates('teq.trs.head.date', $from, $to);

$result = $query->get();

echo count($result), ' row(s) from ', $from->format('Y-m-d'), ' to ', $to->format('Y-m-d'), PHP_EOL;

foreach ($result as $index => $row) {
    $proposal = $row->nullableString('ivb.trs.head.number');
    $invoice = $row->nullableString('inv.trs.head.number');

    echo sprintf(
        '[%d/%d] %s customer %s project %s: %s, value %s, proposed %s%s%s',
        $index + 1,
        count($result),
        $row->date('teq.trs.head.date')->format('Y-m-d'),
        $row->nullableString('teq.trs.head.customer') ?? '-',
        $row->string('teq.trs.head.project1'),
        $row->string('ivb.trs.line.source'),
        $row->amount('teq.trs.line.valueext'),
        $row->amount('ivb.trs.line.value'),
        $proposal === null ? '' : ', proposal ' . $proposal,
        $invoice === null ? ', not invoiced' : ', invoice ' . $invoice,
    ), PHP_EOL;
}
```
