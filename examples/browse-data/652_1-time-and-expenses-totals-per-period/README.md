# Time & Expenses totals per period (652_1)

Browse code `652_1` (`BrowseCode::TimeAndExpensesTotalsPerPeriod`, "Uren en onkosten (Totalen per periode)"): the hours, expenses and quantities of Time & Expenses summed per period, with the same criteria as [650_1](../650_1-time-and-expenses-details/).

<!-- twinfield-documentation:start -->
Twinfield documentation: [Browse data](https://developers.twinfield.com/documentation/api/request-data/browse-data/).
<!-- twinfield-documentation:end -->

- `teq.trs.head.year` and `teq.trs.head.period` as columns give one row per period; add `user` or `project1` to split them further.
- `betweenDates('teq.trs.head.date', $from, $to)`: the date is a criterion only. So is `teq.trs.head.yearperiod` (`2026/03`).
- `teq.trs.line.timevalueext` is the external value of the hours, `timevalueint` the internal value.
- Time & Expenses is a separate module of Twinfield: a company without it gives no rows.

Criteria: year/period, date, user, cost centre of the user, hour code, authoriser, customer, project, cost centre of the project, activity and status. See [`browse-definitions/652_1.xml`](../../../browse-definitions/652_1.xml) and the [browse data guide](https://php.twinfield.solvebeam.com/guides/browse-data/).

## Code

```php
$twinfield = Example::twinfield();

$year = (int) ($argv[1] ?? Example::lastYear($twinfield));
$from = new DateTimeImmutable($year . '-01-01');
$to = new DateTimeImmutable($year . '-12-31');

$query = $twinfield->browse(BrowseCode::TimeAndExpensesTotalsPerPeriod)
    ->columns(
        'teq.trs.head.year',
        'teq.trs.head.period',
        'teq.trs.head.user',
        'teq.trs.head.project1',
        'teq.trs.line.time',
        'teq.trs.line.timevalueext',
        'teq.trs.line.expense',
    )
    ->betweenDates('teq.trs.head.date', $from, $to);

$result = $query->get();

echo count($result), ' row(s) from ', $from->format('Y-m-d'), ' to ', $to->format('Y-m-d'), PHP_EOL;

foreach ($result as $index => $row) {
    echo sprintf(
        '[%d/%d] %d period %d, %s, project %s: %s h, %s, expenses %s',
        $index + 1,
        count($result),
        $row->int('teq.trs.head.year'),
        $row->int('teq.trs.head.period'),
        $row->string('teq.trs.head.user'),
        $row->string('teq.trs.head.project1'),
        $row->nullableDecimal('teq.trs.line.time') ?? '0',
        $row->amount('teq.trs.line.timevalueext'),
        $row->amount('teq.trs.line.expense'),
    ), PHP_EOL;
}
```
