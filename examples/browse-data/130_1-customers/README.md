# Customers (130_1)

Browse code `130_1` (`BrowseCode::Customers`, "Debiteuren"): the transaction lines of customers with their payment status, due date and the credit limit of the customer. [100](../100-customer-transactions/) has fewer fields; [130_2](../130_2-customers-v2/) and [130_3](../130_3-customers-v3/) have more criteria.

<!-- twinfield-documentation:start -->
Twinfield documentation: [Browse data](https://developers.twinfield.com/documentation/api/request-data/browse-data/).
<!-- twinfield-documentation:end -->

- `equal('fin.trs.line.matchstatus', 'available')`: open items. `matched` gives the paid items, `proposed` the items in a payment proposal.
- `fin.trs.head.customer.creditlimit` is the credit limit of the customer, an `Amount`.
- `like('fin.trs.head.code', 'VRK*')`: the day book is a `like` criterion in 130_1.
- `between('fin.trs.head.yearperiod', '2000/00', …)`: open items can be old, so start early.

Criteria: period, day book, status, general ledger account, customer and payment status. See [`browse-definitions/130_1.xml`](../../../browse-definitions/130_1.xml) and the [browse data guide](https://php-twinfield.solvebeam.com/guides/browse-data/).

## Code

```php
$twinfield = Example::twinfield();

$year = Example::lastYear($twinfield);
$customer = $argv[1] ?? null;

$query = $twinfield->browse(BrowseCode::Customers)
    ->columns(
        'fin.trs.line.dim2',
        'fin.trs.line.dim2name',
        'fin.trs.head.customer.creditlimit',
        'fin.trs.head.code',
        'fin.trs.head.number',
        'fin.trs.line.invnumber',
        'fin.trs.line.datedue',
        'fin.trs.line.basevaluesigned',
        'fin.trs.line.openbasevaluesigned',
    )
    ->between('fin.trs.head.yearperiod', '2000/00', sprintf('%d/55', $year))
    ->equal('fin.trs.head.status', 'normal')
    ->equal('fin.trs.line.matchstatus', 'available');

if ($customer !== null) {
    $query = $query->between('fin.trs.line.dim2', $customer, $customer);
}

$result = $query->get();

echo count($result), ' open item(s)', $customer === null ? '' : ' of customer ' . $customer, PHP_EOL;

foreach ($result as $index => $row) {
    $due = $row->nullableDate('fin.trs.line.datedue');

    echo sprintf(
        '[%d/%d] %s %s (credit limit %s), %s %d invoice %s, due %s: %s, open %s',
        $index + 1,
        count($result),
        $row->string('fin.trs.line.dim2'),
        $row->nullableString('fin.trs.line.dim2name') ?? '',
        $row->amount('fin.trs.head.customer.creditlimit'),
        $row->string('fin.trs.head.code'),
        $row->int('fin.trs.head.number'),
        $row->nullableString('fin.trs.line.invnumber') ?? '-',
        $due === null ? '-' : $due->format('Y-m-d'),
        $row->amount('fin.trs.line.basevaluesigned'),
        $row->amount('fin.trs.line.openbasevaluesigned'),
    ), PHP_EOL;
}
```

## Run

```sh
php examples/browse-data/130_1-customers/example.php        # all open items
php examples/browse-data/130_1-customers/example.php 1000   # the open items of customer 1000
```
