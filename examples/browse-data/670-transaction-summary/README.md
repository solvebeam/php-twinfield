# Transaction summary (670)

Browse code `670` (`BrowseCode::TransactionSummary`, "Transactieoverzicht"): the number of transactions and transaction lines per day book and period. Use it to see how much data a period has before you download it, or to check a shadow database.

<!-- twinfield-documentation:start -->
Twinfield documentation: [Browse data](https://developers.twinfield.com/documentation/api/request-data/browse-data/).
<!-- twinfield-documentation:end -->

- `fin.trs.head.count` and `fin.trs.line.count` are numbers: `int()`.
- `fin.trs.head.inpdate` is a criterion only: `betweenDateTimes('fin.trs.head.inpdate', $from, $to)` counts the transactions entered in that time.
- The rows are totals: `$row->transactionLine` is null.

Criteria: period and input date. See [`browse-definitions/670.xml`](../../../browse-definitions/670.xml) and the [browse data guide](https://php.twinfield.solvebeam.com/guides/browse-data/).

## Code

```php
$twinfield = Example::twinfield();

$year = (int) ($argv[1] ?? Example::lastYear($twinfield));

$query = $twinfield->browse(BrowseCode::TransactionSummary)
    ->columns(
        'fin.trs.head.yearperiod',
        'fin.trs.head.code',
        'fin.trs.head.count',
        'fin.trs.line.count',
    )
    ->between('fin.trs.head.yearperiod', sprintf('%d/00', $year), sprintf('%d/55', $year));

$result = $query->get();

echo count($result), ' day book(s) and period(s) in ', $year, PHP_EOL;

$transactions = 0;
$lines = 0;

foreach ($result as $index => $row) {
    $transactions += $row->int('fin.trs.head.count');
    $lines += $row->int('fin.trs.line.count');

    echo sprintf(
        '[%d/%d] %s %s: %d transaction(s), %d line(s)',
        $index + 1,
        count($result),
        $row->period('fin.trs.head.yearperiod'),
        $row->string('fin.trs.head.code'),
        $row->int('fin.trs.head.count'),
        $row->int('fin.trs.line.count'),
    ), PHP_EOL;
}

echo 'Total: ', $transactions, ' transaction(s), ', $lines, ' line(s)', PHP_EOL;
```
