# Suppliers (230_2)

Browse code `230_2` (`BrowseCode::SuppliersV2`, "Crediteuren (v2)"): the transaction lines of suppliers, like [230_1](../230_1-suppliers/), with the payment run, the open amount in the currency of the transaction and the change date of the line as criteria.

<!-- twinfield-documentation:start -->
Twinfield documentation: [Browse data](https://developers.twinfield.com/documentation/api/request-data/browse-data/).
<!-- twinfield-documentation:end -->

- `fin.trs.line.payrun`: the payment run the line is in, empty when it is not in one.
- `betweenDateTimes('fin.trs.line.modified', $since, $now)`: the lines that changed in that time, e.g. because they were paid.
- `fin.trs.line.openvaluesigned` is the open amount in the currency of the transaction and can be a criterion.

Criteria: period, day book, status, change date of the transaction and of the line, general ledger account, supplier, amount, open amount and payment status. See [`browse-definitions/230_2.xml`](../../../browse-definitions/230_2.xml) and the [browse data guide](https://php-twinfield.solvebeam.com/guides/browse-data/).

## Code

```php
$twinfield = Example::twinfield();

$year = Example::lastYear($twinfield);

$query = $twinfield->browse(BrowseCode::SuppliersV2)
    ->columns(
        'fin.trs.line.dim2',
        'fin.trs.line.dim2name',
        'fin.trs.head.code',
        'fin.trs.head.number',
        'fin.trs.line.invnumber',
        'fin.trs.line.datedue',
        'fin.trs.line.openvaluesigned',
        'fin.trs.line.matchstatus',
        'fin.trs.line.payrun',
    )
    ->between('fin.trs.head.yearperiod', '2000/00', sprintf('%d/55', $year))
    ->equal('fin.trs.head.status', 'normal')
    ->equal('fin.trs.line.matchstatus', 'available');

$result = $query->get();

echo count($result), ' open item(s)', PHP_EOL;

foreach ($result as $index => $row) {
    $due = $row->nullableDate('fin.trs.line.datedue');
    $run = $row->nullableString('fin.trs.line.payrun');

    echo sprintf(
        '[%d/%d] %s %s, %s %d invoice %s, due %s: open %s%s',
        $index + 1,
        count($result),
        $row->string('fin.trs.line.dim2'),
        $row->nullableString('fin.trs.line.dim2name') ?? '',
        $row->string('fin.trs.head.code'),
        $row->int('fin.trs.head.number'),
        $row->nullableString('fin.trs.line.invnumber') ?? '-',
        $due === null ? '-' : $due->format('Y-m-d'),
        $row->amount('fin.trs.line.openvaluesigned'),
        $run === null ? ', not in a payment run' : ', payment run ' . $run,
    ), PHP_EOL;
}
```
