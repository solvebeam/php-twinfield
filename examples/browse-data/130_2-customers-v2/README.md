# Customers (130_2)

Browse code `130_2` (`BrowseCode::CustomersV2`, "Debiteuren (v2)"): the transaction lines of customers, like [130_1](../130_1-customers/), with the open amount in the currency of the transaction and the change date of the line as criteria. Use it to find the customer lines that changed since the last time, e.g. when they were paid.

<!-- twinfield-documentation:start -->
Twinfield documentation: [Browse data](https://developers.twinfield.com/documentation/api/request-data/browse-data/).
<!-- twinfield-documentation:end -->

- `betweenDateTimes('fin.trs.line.modified', $since, $now)`: the lines that changed in that time, also by matching. The SDK converts the moments to UTC.
- `fin.trs.line.matchstatus`, `matchdate` and `matchnumber`: whether the line is paid (`matched`), when, and with which match.
- `fin.trs.line.openvaluesigned` is the open amount in the currency of the transaction and can be a criterion, e.g. `notBetween('fin.trs.line.openvaluesigned', '0.00', '0.00')`.

Criteria: period, day book, status, change date of the transaction and of the line, general ledger account, customer, open amount and payment status. See [`browse-definitions/130_2.xml`](../../../browse-definitions/130_2.xml) and the [browse data guide](https://php-twinfield.solvebeam.com/guides/browse-data/).

## Code

```php
$twinfield = Example::twinfield();

$year = Example::lastYear($twinfield);
$since = new DateTimeImmutable($argv[1] ?? '-30 days');

$query = $twinfield->browse(BrowseCode::CustomersV2)
    ->columns(
        'fin.trs.line.dim2',
        'fin.trs.head.code',
        'fin.trs.head.number',
        'fin.trs.line.invnumber',
        'fin.trs.line.valuesigned',
        'fin.trs.line.openvaluesigned',
        'fin.trs.line.matchstatus',
        'fin.trs.line.matchdate',
        'fin.trs.line.modified',
    )
    ->between('fin.trs.head.yearperiod', '2000/00', sprintf('%d/55', $year))
    ->equal('fin.trs.head.status', 'normal')
    ->betweenDateTimes('fin.trs.line.modified', $since, new DateTimeImmutable());

$result = $query->get();

echo count($result), ' customer line(s) changed since ', $since->format('Y-m-d H:i'), PHP_EOL;

foreach ($result as $index => $row) {
    $paid = $row->nullableDate('fin.trs.line.matchdate');

    echo sprintf(
        '[%d/%d] %s %s %d invoice %s: %s, open %s, %s%s, changed %s',
        $index + 1,
        count($result),
        $row->string('fin.trs.line.dim2'),
        $row->string('fin.trs.head.code'),
        $row->int('fin.trs.head.number'),
        $row->nullableString('fin.trs.line.invnumber') ?? '-',
        $row->amount('fin.trs.line.valuesigned'),
        $row->amount('fin.trs.line.openvaluesigned'),
        $row->string('fin.trs.line.matchstatus'),
        $paid === null ? '' : ' on ' . $paid->format('Y-m-d'),
        $row->dateTime('fin.trs.line.modified')->format('Y-m-d H:i'),
    ), PHP_EOL;
}
```

## Run

```sh
php examples/browse-data/130_2-customers-v2/example.php                      # changed in the last 30 days
php examples/browse-data/130_2-customers-v2/example.php '2026-03-01 00:00'   # changed since 1 March 2026
```
