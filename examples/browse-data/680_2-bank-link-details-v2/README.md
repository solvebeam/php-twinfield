# Bank link details (680_2)

Browse code `680_2` (`BrowseCode::BankLinkDetailsV2`, "Bankkoppeling details (v2)"): the bank books of the company with their IBAN, currency and the kind of link for account information, payments and direct debits, and when the consent of the bank expires.

<!-- twinfield-documentation:start -->
Twinfield documentation: [Browse data](https://developers.twinfield.com/documentation/api/request-data/browse-data/).
<!-- twinfield-documentation:end -->

- `fin.bnk.accountintegrationtype`, `payments` and `directdebits`: `none`, `classic`, `commercial` or `Bank feed` (the bank link).
- `equal('fin.bnk.accountstatus', 'active')`: only active bank books, not the archived ones. It is the only criterion.
- `fin.bnk.consentexpirydate` is a date and empty without a bank link: `nullableDate()`.

Criteria: status. See [`browse-definitions/680_2.xml`](../../../browse-definitions/680_2.xml) and the [browse data guide](https://php-twinfield.solvebeam.com/guides/browse-data/).

## Code

```php
$twinfield = Example::twinfield();

$query = $twinfield->browse(BrowseCode::BankLinkDetailsV2)
    ->columns(
        'fin.bnk.transactiontype',
        'fin.bnk.iban',
        'fin.bnk.currency',
        'fin.bnk.accountintegrationtype',
        'fin.bnk.payments',
        'fin.bnk.directdebits',
        'fin.bnk.consentexpirydate',
    )
    ->equal('fin.bnk.accountstatus', 'active');

$result = $query->get();

echo count($result), ' active bank book(s)', PHP_EOL;

foreach ($result as $index => $row) {
    $consent = $row->nullableDate('fin.bnk.consentexpirydate');

    echo sprintf(
        '[%d/%d] %s IBAN %s %s: account information %s, payments %s, direct debits %s, consent until %s',
        $index + 1,
        count($result),
        $row->string('fin.bnk.transactiontype'),
        $row->string('fin.bnk.iban'),
        $row->string('fin.bnk.currency'),
        $row->string('fin.bnk.accountintegrationtype'),
        $row->string('fin.bnk.payments'),
        $row->string('fin.bnk.directdebits'),
        $consent === null ? '-' : $consent->format('Y-m-d'),
    ), PHP_EOL;
}
```
