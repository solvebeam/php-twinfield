# Time & Expenses details (650_1)

Browse code `650_1` (`BrowseCode::TimeAndExpensesDetails`, "Uren en onkosten (Details)"): every Time & Expenses entry with the user, customer, project, activity and status, and the hours, expenses and quantities, billable and not billable.

<!-- twinfield-documentation:start -->
Twinfield documentation: [Browse data](https://developers.twinfield.com/documentation/api/request-data/browse-data/).
<!-- twinfield-documentation:end -->

- `betweenDates('teq.trs.head.date', $from, $to)`: entries in a date range. `teq.trs.head.yearperiod` (year and month, `2026/03`) and `yearweek` (`2026/12`) are criteria only.
- `teq.trs.head.status`: `entered`, `proposed`, `authorised`, `rejected`, `inuse` or `journalised`; can be a criterion.
- `teq.trs.line.time` are the billable hours, `time_nb` the hours that are not billable; the same for `expense` and `quantity`.
- Time & Expenses is a separate module of Twinfield: a company without it gives no rows.

Criteria: year/month, year/week, date, user, cost centre of the user, hour code, authoriser, customer, project, cost centre of the project, activity and status. See [`browse-definitions/650_1.xml`](../../../browse-definitions/650_1.xml) and the [browse data guide](https://php.twinfield.solvebeam.com/guides/browse-data/).

## Code

```php
$twinfield = Example::twinfield();

$year = (int) ($argv[1] ?? Example::lastYear($twinfield));
$from = new DateTimeImmutable($year . '-01-01');
$to = new DateTimeImmutable($year . '-12-31');

$query = $twinfield->browse(BrowseCode::TimeAndExpensesDetails)
    ->columns(
        'teq.trs.head.date',
        'teq.trs.head.user',
        'teq.trs.head.customer',
        'teq.trs.head.project1',
        'teq.trs.head.project2',
        'teq.trs.head.status',
        'teq.trs.line.time',
        'teq.trs.line.time_nb',
        'teq.trs.line.expense',
        'teq.trs.line.description',
    )
    ->betweenDates('teq.trs.head.date', $from, $to);

$result = $query->get();

echo count($result), ' row(s) from ', $from->format('Y-m-d'), ' to ', $to->format('Y-m-d'), PHP_EOL;

foreach ($result as $index => $row) {
    echo rtrim(sprintf(
        '[%d/%d] %s %s, customer %s, project %s activity %s (%s): %s h, %s h not billable, expenses %s %s',
        $index + 1,
        count($result),
        $row->date('teq.trs.head.date')->format('Y-m-d'),
        $row->string('teq.trs.head.user'),
        $row->nullableString('teq.trs.head.customer') ?? '-',
        $row->string('teq.trs.head.project1'),
        $row->nullableString('teq.trs.head.project2') ?? '-',
        $row->string('teq.trs.head.status'),
        $row->nullableDecimal('teq.trs.line.time') ?? '0',
        $row->nullableDecimal('teq.trs.line.time_nb') ?? '0',
        $row->amount('teq.trs.line.expense'),
        $row->nullableString('teq.trs.line.description') ?? '',
    )), PHP_EOL;
}
```
