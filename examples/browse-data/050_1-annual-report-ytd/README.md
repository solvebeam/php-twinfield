# Annual report year to date (050_1)

Browse code `050_1` (`BrowseCode::AnnualReportYearToDate`, "Annual Report YTD"): the balance per general ledger account from the start of the year up to a period, summed by Twinfield. Use [040_1](../040_1-annual-report-totals/) for totals with more fields, such as the account groups.

<!-- twinfield-documentation:start -->
Twinfield documentation: [Browse data](https://developers.twinfield.com/documentation/api/request-data/browse-data/).
<!-- twinfield-documentation:end -->

- `between('fin.trs.head.yearperiod', '2026/00', $to)`: from the opening balance (period `00`) up to and including `$to`.
- `equal('fin.trs.head.balanceregimeprompt', $regime)`: the regime is required; Twinfield uses `Generic` when you leave it out.
- Twinfield groups the lines by the columns you ask for, so ask only for the columns you want totals by. The rows are totals: `$row->transactionLine` is null.

Criteria: period, status, general ledger account and regime. See [`browse-definitions/050_1.xml`](../../../browse-definitions/050_1.xml) and the [browse data guide](https://php.twinfield.solvebeam.com/guides/browse-data/).

## Code

```php
$twinfield = Example::twinfield();

$to = Period::fromString($argv[1] ?? Example::lastYear($twinfield) . '/12');
$regime = Regime::from($argv[2] ?? 'Generic');

$query = $twinfield->browse(BrowseCode::AnnualReportYearToDate)
    ->columns(
        'fin.trs.line.dim1',
        'fin.trs.line.dim1name',
        'fin.trs.line.dim1type',
        'fin.trs.line.basevaluesigned',
    )
    ->between('fin.trs.head.yearperiod', sprintf('%d/00', $to->year), $to)
    ->equal('fin.trs.head.status', 'normal')
    ->equal('fin.trs.head.balanceregimeprompt', $regime);

$result = $query->get();

echo count($result), ' general ledger account(s) up to ', $to, ', regime ', $regime->value, PHP_EOL;

$totals = [];

foreach ($result as $index => $row) {
    $type = $row->string('fin.trs.line.dim1type');
    $balance = $row->amount('fin.trs.line.basevaluesigned');
    $totals[$type] = ($totals[$type] ?? Amount::zero())->plus($balance);

    echo sprintf(
        '[%d/%d] %s %s %s: %s',
        $index + 1,
        count($result),
        $type,
        $row->string('fin.trs.line.dim1'),
        $row->nullableString('fin.trs.line.dim1name') ?? '',
        $balance,
    ), PHP_EOL;
}

foreach ($totals as $type => $total) {
    echo 'Total ', $type, ': ', $total, PHP_EOL;
}
```

## Run

```sh
php examples/browse-data/050_1-annual-report-ytd/example.php                  # up to period 12 of the last year
php examples/browse-data/050_1-annual-report-ytd/example.php 2026/06 Fiscal   # up to June 2026, fiscal regime
```
