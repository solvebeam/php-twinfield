# Bank transactions (410)

Browse code `410` (`BrowseCode::BankTransactions`, "Bankkaart"): the transaction lines of one bank book per statement, with the start and closing balance of the statement.

<!-- twinfield-documentation:start -->
Twinfield documentation: [Browse data](https://developers.twinfield.com/documentation/api/request-data/browse-data/).
<!-- twinfield-documentation:end -->

- `equal('fin.trs.head.bankcode', $book)`: the bank book is required. Without it Twinfield answers with a server error. The criterion is not a column: use `fin.trs.head.code`.
- `fin.trs.head.stmnumber` is the statement number, `startvalue` and `closevalue` the balance before and after the statement.
- `equal('fin.trs.head.status', 'normal')`: provisional and final. Without it you also get the drafts, with number `-1`.

Criteria: period, bank book, number, statement number, general ledger account, amount and status. See [`browse-definitions/410.xml`](../../../browse-definitions/410.xml) and the [browse data guide](https://php.twinfield.solvebeam.com/guides/browse-data/).

## Code

```php
$twinfield = Example::twinfield();

$book = $argv[1] ?? 'BNK';
$year = (int) ($argv[2] ?? Example::lastYear($twinfield));

$query = $twinfield->browse(BrowseCode::BankTransactions)
    ->columns(
        'fin.trs.head.code',
        'fin.trs.head.stmnumber',
        'fin.trs.head.startvalue',
        'fin.trs.head.closevalue',
        'fin.trs.head.number',
        'fin.trs.line.dim1',
        'fin.trs.line.dim1name',
        'fin.trs.line.basevaluesigned',
    )
    ->between('fin.trs.head.yearperiod', sprintf('%d/00', $year), sprintf('%d/55', $year))
    ->equal('fin.trs.head.bankcode', $book)
    ->equal('fin.trs.head.status', 'normal');

$result = $query->get();

echo count($result), ' line(s) of bank book ', $book, ' in ', $year, PHP_EOL;

foreach ($result as $index => $row) {
    echo sprintf(
        '[%d/%d] %s statement %d (%s to %s), %d line %d: %s %s %s',
        $index + 1,
        count($result),
        $row->string('fin.trs.head.code'),
        $row->int('fin.trs.head.stmnumber'),
        $row->amount('fin.trs.head.startvalue'),
        $row->amount('fin.trs.head.closevalue'),
        $row->int('fin.trs.head.number'),
        $row->transactionLine?->line,
        $row->string('fin.trs.line.dim1'),
        $row->nullableString('fin.trs.line.dim1name') ?? '',
        $row->amount('fin.trs.line.basevaluesigned'),
    ), PHP_EOL;
}
```

## Run

```sh
php examples/browse-data/410-bank-transactions/example.php            # bank book BNK, the last year
php examples/browse-data/410-bank-transactions/example.php ING 2026   # bank book ING in 2026
```
