# Project transactions (300)

Browse code `300` (`BrowseCode::ProjectTransactions`, "Projectkaart"): the transaction lines booked on projects (dimension 3), with the general ledger account and cost centre.

<!-- twinfield-documentation:start -->
Twinfield documentation: [Browse data](https://developers.twinfield.com/documentation/api/request-data/browse-data/).
<!-- twinfield-documentation:end -->

- `fin.trs.line.dim3` is the project, `dim1` the general ledger account and `dim2` the cost centre or relation.
- `between('fin.trs.line.dim3', $project, $project)`: one project.
- The status is not a criterion in 300: you get all transactions, also drafts (number `-1`). Ask for `fin.trs.head.status` as column and skip them when needed.
- `fin.trs.head.yearperiod` is visible in 300: it can be a column as well as a criterion.

Criteria: period, day book, number, the three dimensions, invoice number and regime. See [`browse-definitions/300.xml`](../../../browse-definitions/300.xml) and the [browse data guide](https://php-twinfield.solvebeam.com/guides/browse-data/).

## Code

```php
$twinfield = Example::twinfield();

$year = (int) ($argv[1] ?? Example::lastYear($twinfield));
$project = $argv[2] ?? null;

$query = $twinfield->browse(BrowseCode::ProjectTransactions)
    ->columns(
        'fin.trs.line.dim3',
        'fin.trs.line.dim3name',
        'fin.trs.head.yearperiod',
        'fin.trs.head.code',
        'fin.trs.head.number',
        'fin.trs.head.status',
        'fin.trs.line.dim1',
        'fin.trs.line.dim2',
        'fin.trs.line.basevaluesigned',
    )
    ->between('fin.trs.head.yearperiod', sprintf('%d/00', $year), sprintf('%d/55', $year));

if ($project !== null) {
    $query = $query->between('fin.trs.line.dim3', $project, $project);
}

$result = $query->get();

echo count($result), ' project line(s) in ', $year, $project === null ? '' : ' of project ' . $project, PHP_EOL;

foreach ($result as $index => $row) {
    echo sprintf(
        '[%d/%d] %s %s, %s %s %d (%s): %s %s %s',
        $index + 1,
        count($result),
        $row->string('fin.trs.line.dim3'),
        $row->nullableString('fin.trs.line.dim3name') ?? '',
        $row->period('fin.trs.head.yearperiod'),
        $row->string('fin.trs.head.code'),
        $row->int('fin.trs.head.number'),
        $row->string('fin.trs.head.status'),
        $row->string('fin.trs.line.dim1'),
        $row->nullableString('fin.trs.line.dim2') ?? '-',
        $row->amount('fin.trs.line.basevaluesigned'),
    ), PHP_EOL;
}
```

## Run

```sh
php examples/browse-data/300-project-transactions/example.php              # the last year
php examples/browse-data/300-project-transactions/example.php 2026 P0001   # project P0001 in 2026
```

Add `TWINFIELD_DEBUG=1` to see the SOAP requests and responses.
