# Annual report multicurrency (060)

Browse code `060` (`BrowseCode::AnnualReportTotalsMulticurrency`, "Annual Report MC"): totals per general ledger account and currency, summed by Twinfield. Each row has the amount in the currency of the transaction and in the base currency of the company.

<!-- twinfield-documentation:start -->
Twinfield documentation: [Browse data](https://developers.twinfield.com/documentation/api/request-data/browse-data/).
<!-- twinfield-documentation:end -->

- `fin.trs.head.curcode` with `fin.trs.line.valuesigned`: the total in the currency of the transactions; `fin.trs.line.basevaluesigned` is the same total in the base currency.
- `fin.trs.line.debitcredit` as column gives separate totals for debit and credit.
- `equal('fin.trs.head.balanceregimeprompt', $regime)`: the regime is required; Twinfield uses `Generic` when you leave it out. `fin.trs.head.reportingstructure` can be a criterion as well.
- The rows are totals: `$row->transactionLine` is null.

Criteria: period, status, general ledger account, regime and reporting structure. See [`browse-definitions/060.xml`](../../../browse-definitions/060.xml) and the [browse data guide](https://php.twinfield.solvebeam.com/guides/browse-data/).

## Code

```php
$twinfield = Example::twinfield();

$year = (int) ($argv[1] ?? Example::lastYear($twinfield));
$regime = Regime::from($argv[2] ?? 'Generic');

$query = $twinfield->browse(BrowseCode::AnnualReportTotalsMulticurrency)
    ->columns(
        'fin.trs.line.dim1',
        'fin.trs.line.dim1name',
        'fin.trs.head.curcode',
        'fin.trs.line.debitcredit',
        'fin.trs.line.valuesigned',
        'fin.trs.line.basevaluesigned',
    )
    ->between('fin.trs.head.yearperiod', sprintf('%d/00', $year), sprintf('%d/55', $year))
    ->equal('fin.trs.head.status', 'final')
    ->equal('fin.trs.head.balanceregimeprompt', $regime);

$result = $query->get();

echo count($result), ' total(s) per account and currency in ', $year, ', regime ', $regime->value, PHP_EOL;

foreach ($result as $index => $row) {
    echo sprintf(
        '[%d/%d] %s %s %s: %s %s (base %s)',
        $index + 1,
        count($result),
        $row->string('fin.trs.line.dim1'),
        $row->nullableString('fin.trs.line.dim1name') ?? '',
        $row->string('fin.trs.line.debitcredit'),
        $row->string('fin.trs.head.curcode'),
        $row->amount('fin.trs.line.valuesigned'),
        $row->amount('fin.trs.line.basevaluesigned'),
    ), PHP_EOL;
}
```

## Run

```sh
php examples/browse-data/060-annual-report-multicurrency/example.php   # the last year, generic regime
```

Add `TWINFIELD_DEBUG=1` to see the SOAP requests and responses.

```text
[2/3] 1300 Debiteuren debit: USD 500.00 (base 462.50)
[3/3] 8000 Omzet credit: USD -500.00 (base -462.50)
```
